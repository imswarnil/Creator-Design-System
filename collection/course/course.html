Questions

Do I need to know CSS already?

For this one, no. It starts at what a token is. The layout and motion courses assume you have written a stylesheet before.

How long do I have access?

Once you have a course, you have it. There is no renewal, because a renewal would make the course a subscription wearing a price tag.

Is there a certificate?

Yes, at the end of each course. It is a page with your name on it — useful for a manager, and honest about being exactly that.

What if it is not for me?

Thirty days, no questions, no form asking why. Email and it is done.
